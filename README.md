# Cheng-Ru Chou — Academic Website

English academic homepage for Cheng-Ru Chou, built for GitHub Pages.

## Publish with GitHub Pages

1. Keep these files on the repository's `main` branch.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then save.

The site will be available at <https://chengruchou.github.io>.

## Update workflow

The source design is maintained separately. Replace `index.html`, `assets/`,
and `favicon.svg` after generating a new static release.
